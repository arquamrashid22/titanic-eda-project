# 🚢 Titanic Exploratory Data Analysis (EDA)

## 📊 Project Overview
This project performs Exploratory Data Analysis (EDA) on the Titanic dataset to understand the factors that influenced passenger survival.

The analysis explores relationships between variables such as gender, age, class, and fare using Python data analysis and visualization tools.

---

## 🎯 Objective
To analyze the Titanic dataset and answer key questions like:
- Who survived more: male or female?
- Which passenger class had the highest survival rate?
- Does fare affect survival chances?
- What is the role of age in survival?

---

## 🧰 Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📂 Dataset
The dataset contains information about Titanic passengers:
- Passenger class
- Gender
- Age
- Fare
- Survival status
- Embark town

---

## 🧹 Data Cleaning
- Handled missing values in age using median
- Filled missing embark_town using mode
- Checked null values and ensured clean dataset

---

## 📊 Exploratory Data Analysis

### 1. Survival Analysis
- Survival count of passengers
- Survival rate by gender
- Survival rate by class

### 2. Distribution Analysis
- Age distribution of passengers
- Fare distribution analysis

### 3. Relationship Analysis
- Age vs Fare (Scatterplot)
- Correlation between numerical features

### 4. Group Analysis
- Average survival rate by gender
- Average survival rate by class
- Fare comparison by class and gender

---

## 📈 Key Insights
- Female passengers had higher survival rates than males
- First-class passengers had the highest survival probability
- Higher fare passengers had better survival chances
- Age had less impact compared to gender and class
- Class and gender were the strongest survival factors

---
